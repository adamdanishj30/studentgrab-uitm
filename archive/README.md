# 📦 Archive Directory

This folder contains archived, unused, or deprecated files preserved for reference.

---

## 📁 `boilerplate/`
Contains boilerplate assets and stylesheets created during the initial Vite React project initialization that are not used by the application:
- `App.css`: Default Vite starter CSS. Replaced by Tailwind CSS in `src/index.css`.
- `react.svg`: Default React logo SVG.
- `vite.svg`: Default Vite logo SVG.
- `hero.png`: Default starter placeholder image.
